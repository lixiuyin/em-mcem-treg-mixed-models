# Deep Learning Real-Data Empirical Analysis — Reproduction Guide

Corresponds to **Chapter 5** of the thesis. Two pipelines apply the EM/MCEM implementations from Chapters 3 and 4 to real data, **reusing algorithm code** from `t-regression/` and `two-level-model/` with only the data replaced.

## Environment

- **R 4.5**: `this.path`, `MASS`, `Matrix`, `lme4` (gold-standard comparison). Replot scripts use English labels, the macOS `quartz` PNG device, and `CJK <- "sans"`; on non-macOS systems change the PNG device type if needed.
- **Python 3.13**: `torch`, `torchvision`, `datasets`, `scikit-learn`, `numpy`, `pandas`. Embedding extraction automatically uses MPS (Apple GPU), falling back to CPU if unavailable.
- Random seed fixed at `20250529` (Python sampling/sub-sampling and R-side MCEM).

## Pipeline 1: t Regression — `empirical-t-utkface/`

| Step | Script | Description |
|---|---|---|
| 1 | `code/01_extract_embeddings.py` | Samples 8,000 faces from Hugging Face `py97/UTKFace-Cropped` (MIT, ~107 MB); extracts 2,048-dim ResNet-50 embeddings → PCA to 30 dims → `data/utkface_t_regression.csv` |
| 2 | `code/02_tregression_real.R` | OLS baseline; selects nu* via profile marginal likelihood of nu; EM/MCEM at nu*; dual validation against `optim` marginal MLE and `MASS::rlm`; outputs `treg_summary.txt` and regenerated `treg_results.rds` |
| 3 | `code/03_replot.R` | Redraws 4 figures from saved results |

**Key results**: ν*=6; $t$ marginal likelihood exceeds normal by +151; maximum coefficient difference EM vs. optim 0.0002, EM vs. rlm correlation 1.0; among the 10% of samples most strongly down-weighted, 59.5% are aged ≥60 (vs. 11.3% in the full sample).

> Note: the original `t-regression/utils.R` uses `diag(gamma)` (dense $n\times n$ matrix), suitable only for $n\approx500$ simulations; `02_tregression_real.R` switches to row-wise scaling `w*X` (mathematically equivalent to equations 3-14/3-19/3-22 of the thesis), enabling $n=8000$.

## Pipeline 2: Two-Level Linear Model — `empirical-2level-cifar10h/`

| Step | Script | Description |
|---|---|---|
| 1 | `code/01_build_lmm_data.py` | Reads the committed raw CIFAR-10H trials (`cifar10h-raw.zip`, from `github.com/jcpeterson/cifar-10h`) + soft-label probs; cleans reaction times; computes image difficulty as human soft-label entropy; selects J=300 annotators → `data/cifar10h_lmm_main.csv` (full dataset also written as `_full.csv`, git-ignored) |
| 2 | `code/02_lmm_real.R` | Reuses the thesis two-level model EM/MCEM (**only** overrides the three accessors `get_X_j/y_j/W_j` to read grouped data, avoiding a huge block-diagonal matrix); drops 1 rank-deficient annotator so the fit uses **J=299** (N=59699); runs EM + MCEM(M=20/50/200); `lme4` gold-standard comparison; outputs `lmm_summary.txt` and regenerated `lmm_results.rds` |
| 3 | `code/03_replot.R` | Redraws 3 figures from saved results |
| 4 | `code/04_robustness_full.R` | Robustness check: re-runs deterministic EM on the full annotator set (J=2567 after dropping rank-deficient annotators) and verifies the fixed effects / σ² / ICC are consistent with the J=299 main analysis; reads `cifar10h_lmm_full.csv` (regenerate via step 1), prints a console summary, and writes `output/lmm_full_robustness.rds` |

**Key results**: γ=(intercept 7.65, difficulty +0.13, correct −0.26, trial −0.03); σ²=0.1191, exactly matching lme4 (marginal log-likelihood −22423.06 agrees point-by-point); random-effect SD agrees to 3 decimal places; intercept ICC=0.473; MCEM agrees with EM to 4 decimal places.

> Model specification: q=0, $W_j=I_4$ (the four level-1 coefficients: intercept, difficulty, correct, trial), i.e. a random-coefficient model $\boldsymbol\beta_j\sim N(\boldsymbol\gamma,D)$, corresponding to the closed-form GLS γ update in equation (4-25b) of the thesis and the D update (equation (4-32)) with divisor J under a flat prior.

## Execution Order

```bash
# Pipeline 1
python3 empirical-t-utkface/code/01_extract_embeddings.py
Rscript  empirical-t-utkface/code/02_tregression_real.R
Rscript  empirical-t-utkface/code/03_replot.R
# Pipeline 2
python3 empirical-2level-cifar10h/code/01_build_lmm_data.py
Rscript  empirical-2level-cifar10h/code/02_lmm_real.R
Rscript  empirical-2level-cifar10h/code/03_replot.R
Rscript  empirical-2level-cifar10h/code/04_robustness_full.R   # optional full-set robustness check
```
